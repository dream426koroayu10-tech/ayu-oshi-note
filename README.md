# Ayu 推し活ノート

イベンターノート @ayu_11039 の参加イベントをすべて表示する、推し活サイトです。

## 使い方(いちばん簡単な手順)
1. ZIPを展開すると `ayu_oshi_note` フォルダーができます。中身を、そのままGitHubのリポジトリにアップロードします。
   - `.github` フォルダーはドラッグ&ドロップで入らないことがあります。その場合は、GitHubの画面で
     「Add file → Create new file」を選び、ファイル名に `.github/workflows/update-events.yml` と入力して、
     同梱のファイルの中身を貼り付けてください。
2. リポジトリの Settings → Actions → General → Workflow permissions で **Read and write permissions** を選んで保存します。
3. Actions タブ →「Update Eventernote events」→ **Run workflow**(forceはオフのまま)を押します。
4. 数分後に緑のチェックが付けば完了です。`events.json` が最新になり、サイトに反映されます。
5. 公開する場合は Settings → Pages で公開設定をします。以後は毎日(日本時間6時ごろ)自動更新されます。

## 全件取れているかの確認(自動)
- 取得後に、イベンターノートが表示している「参加イベント一覧(N件)」と、集めた件数を突き合わせます。
- **一致したときだけ** `events.json` を書き換えます。一致しなければ赤い×で止まり、今の `events.json` はそのまま残ります。
- サイトの「イベントデータ」欄に「イベンターノートの登録 N件と一致 ✓」と表示されます(同期が成功したあと)。
- Actions のログの最後に、年ごとの件数と「集めた件数 / イベンターノートの表示」が出ます。

## うまくいかないとき
- 赤い×になったら、ログの「エラー:」の行を見てください。どうしても一致しないが内容は正しい、というときだけ、
  「Run workflow」の **force** にチェックを入れると保存できます(サイトには「⚠」付きで差が表示されます)。
- Actions側のアクセスが拒否される場合は、自分のPCで `pip install -r requirements.txt` のあと
  `python sync_events.py` を実行し、できた `events.json` をアップロードしてください。

## 注意
- 同期は公開ページの情報だけを読み取ります。非公開情報やログインが必要な情報は取得しません。
- 同梱の `events.json` は、同期が成功するまでの仮データ(85件)です。同期が成功すると置き換わります。
